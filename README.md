# QNAP TS-230: расследование ограничения PWM системного вентилятора

> Статус: подтверждённое наблюдение на одном QNAP TS-230. Это не официальная
> инструкция QNAP. Изменение сохранности после перезагрузки и обновления QTS
> **ещё не проверено**.

## Результат

После установки **ARCTIC P8 Slim PWM PST 80 mm** (заявлено до 3000 RPM) режим
QTS «100 %» давал примерно **2200 RPM**. Причина оказалась не в прямом
Realtek-PWM sysfs, а в ограничении QNAP для MCU в описании модели:

```ini
[System FAN]
FAN_UNIT = MCU
FAN_1 = I1:C0
MIN_PWM = 51
MAX_PWM = 178
HEAT_SOURCE = SYS, DISK
```

`178 / 255 = 69.8 %`, что хорошо объясняет около `2200 / 3000 RPM`.
После замены `MAX_PWM = 178` на `MAX_PWM = 255` и переключения в GUI QTS
`50 % → 100 %` была показана скорость **2970 RPM**. Штатное QTS-управление,
автоматика температур и контроль вентилятора при этом не отключались.

## Контекст системы

| Параметр | Значение |
| --- | --- |
| NAS | QNAP TS-230 |
| ОС/ядро | QTS / Linux 4.2.8, `aarch64` |
| Заменённый вентилятор | ARCTIC P8 Slim PWM PST, 80 mm, до 3000 RPM |
| Режим QTS на момент наблюдения | GUI 100 %, также `uLinux.conf`: `FAN action=Fixed`, `FAN speed=100` |
| До изменения | ~2200 RPM |
| После изменения | 2970 RPM |

## Хронология и доказательства

1. При 100 % в QTS новый Arctic достигал только около 2200 RPM.
2. В `/etc/config/qfan.conf` были штатные значения:

   ```ini
   qfan_enable=TRUE
   stop_pwm=0
   low_pwm=60
   mid_pwm=150
   high_pwm=255

   # SMART MODE formula=2
   low_sys_temp=40
   high_sys_temp=54
   high_cpu_temp=75
   high_hdd_temp=55
   ```

   Поэтому `qfan.conf` сам по себе не объяснял потолок 70 %.
3. `hwmon0` — `rtk_thermal`; стандартных `fan*`/`pwm*` интерфейсов hwmon нет.
4. В DT присутствует `/sys/firmware/devicetree/base/rtk_fan@9801BC00` с
   `compatible = Realtek,rtd129x-fan`, но `status = disabled`. Свойство `pwms`
   имеет байты `00 00 00 4c 00 00 00 01 00 00 93 f6`: phandle `0x4c`, канал PWM
   1, период `37878 ns` (примерно 26.4 kHz).
5. Доступен Realtek PWM sysfs: `/sys/devices/platform/980070d0.pwm` и
   `/sys/class/pwm/pwmchip0`, с `enable0..3`, `dutyRate0..3`, `out_freq0..3`,
   `clkoutDiv0..3`, `clksrcDiv0..3`. Наблюдалось:

   | Канал | enable | duty | out_freq | clkoutDiv | clksrcDiv |
   | --- | ---: | ---: | ---: | ---: |
   | PWM0 | 1 | 50 % | 12 Hz | 255 | 12 |
   | PWM1 | 0 | 100 % | 26367 Hz | 255 | 1 |
   | PWM2 | 0 | 100 % | 26367 Hz | 255 | 1 |
   | PWM3 | 1 | 50 % | 12 Hz | 255 | 12 |

   Ничего из этого не менялось при GUI `100 % → 50 %`; следовательно, это не
   подтверждённый активный путь управления системным вентилятором. Прямые
   записи в эти регистры намеренно не выполнялись.
6. В `hal_app` есть скрытые строки/команды `se_sys_get/set fan/pwm` и т. п.
   `hal_app --se_enum` показал основной enclosure: `enc_id=0`,
   `enc_sys_id=root`, `fan_no=1`. Однако `hal_app --se_sys_get_fan
   enc_sys_id=root,obj_index=0` и `--se_sys_get_fan_pwm ...` возвратили
   `ret=-2`, RPM/PWM = 0. Этот enclosure API не реализован здесь либо не
   подходит для TS-230.
7. `/lib/libuLinux_hal.so` содержит `HM_Set_Fan_Speed_By_PWM`,
   `i2c_sys_set_root_fan_pwm`, `se_sys_get_fan_pwm_min_max` и ссылку на
   `/etc/model.conf`. Это указывает на маршрут HAL → I²C/MCU.
8. `/etc/model.conf` — symlink на
   `/etc/model_Q04Z0_Q0500_10_10.conf`. В секции `[System FAN]` найден
   `FAN_UNIT = MCU`, `FAN_1 = I1:C0`, `MIN_PWM = 51`, `MAX_PWM = 178`,
   `HEAT_SOURCE = SYS, DISK`.
9. Создана резервная копия
   `/etc/model_Q04Z0_Q0500_10_10.conf.bak`; затем выполнено:

   ```sh
   sudo sed -i 's/^MAX_PWM = 178$/MAX_PWM = 255/' /etc/model_Q04Z0_Q0500_10_10.conf
   ```

10. После GUI-переключения `50 % → 100 %` QTS применил новый потолок:
    **2970 RPM**. Это практически паспортные 3000 RPM и проверяет гипотезу.

## Безопасная повторная проверка

Скопируйте [`scripts/qnap-ts230-fan-cap.sh`](scripts/qnap-ts230-fan-cap.sh) на
NAS и запустите без аргументов. По умолчанию он только читает состояние:

```sh
sh qnap-ts230-fan-cap.sh
```

Скрипт не пишет напрямую в PWM sysfs и не трогает регистры MCU. Перед любым
изменением он требует root, проверяет `/etc/model.conf`, цель симлинка, наличие
секции и текущее значение `MAX_PWM`. Применение требует явного флага:

```sh
sudo sh qnap-ts230-fan-cap.sh --apply-255
```

Он создаёт backup рядом с исходным файлом (если его нет), заменяет ровно одну
строку `MAX_PWM`, затем повторно проверяет результат. После выполнения в QTS
выберите 50 %, примените, подождите примерно 10 секунд; затем выберите 100 %,
примените и подождите 20–30 секунд. Зафиксируйте RPM и температуры.

## Откат

Если существует исходная копия `.bak`, явный откат:

```sh
sudo sh qnap-ts230-fan-cap.sh --rollback
```

Для конкретно созданной копии также допустимо (только после проверки путей):

```sh
sudo cp -p /etc/model_Q04Z0_Q0500_10_10.conf.bak /etc/model_Q04Z0_Q0500_10_10.conf
```

Затем повторите переключение 50 % → 100 % в GUI, чтобы QTS перечитал предел.

## Важные ограничения и дальнейшая работа

* Не проверено, сохраняется ли правка после reboot. Не перезагружайте NAS
  специально только ради этого эксперимента без окна обслуживания.
* QTS update, загрузочные скрипты или генерация профиля модели могут восстановить
  файл. После каждого обновления проверяйте симлинк и `MAX_PWM` в диагностическом
  режиме; не применяйте автоматически.
* Долгосрочно следите за температурами, шумом, ошибками вентилятора и фактическими
  RPM. Изменение повышает только верхний предел; оно не является полной заменой
  температурной политики QTS.
* Не считать адреса и наблюдённые sysfs-каналы инструкцией для записи: они были
  исключены именно потому, что не реагировали на GUI и могут управлять другой
  периферией.

## Полезные команды чтения

```sh
uname -a
cat /etc/config/qfan.conf
readlink /etc/model.conf
grep -n -A5 '^\\[System FAN\\]' /etc/model.conf
ls -l /etc/model_Q04Z0_Q0500_10_10.conf*
find /sys/class/hwmon -maxdepth 2 -type f \( -name 'fan*' -o -name 'pwm*' \)
```

При сборе новых данных храните версию QTS, модель вентилятора, выбранный режим,
RPM до/после и температуры. Не храните в репозитории пароли, токены или дампы,
которые могут содержать учётные данные.
